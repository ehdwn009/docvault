## 레이아웃 개요

로그인 후 전체 화면은 단일 워크스페이스(SCR-100)입니다. 좌측 아이콘 레일(48px)에서 패널을 전환하고, 패널 우측 본문 영역에 뷰어/편집기 또는 설정 콘텐츠가 표시됩니다. 모바일에서는 레일+패널이 드로어(서랍)로 전환됩니다.

## 비고

- **글로벌 내비게이션**: 아이콘 레일이 유일한 전역 내비게이션. 상단 헤더는 두지 않고 뷰어/편집기 헤더에 파일명·액션 버튼을 배치합니다.
- **URL 라우팅**: SPA지만 딥링크를 지원합니다 — `/login`, `/f/{fileId}` (파일 열람), `/admin/*`. 폰에서 특정 문서를 북마크해 바로 열 수 있게 하기 위함입니다.
- **단축키**: `[` 파일 패널 토글, `Ctrl+K` 커맨드 팔레트, `E` 편집 모드, `Ctrl+S` 저장, `Escape` 패널 닫기. 모바일에는 해당 없음.
- **권한 정책**: 모든 화면이 로그인 필수(로그인 화면 제외). 관리자 메뉴는 role=admin에만 렌더링하며 서버 API도 이중으로 검사합니다.
- **반응형 기준**: md(768px) 미만에서 레일은 하단 탭 또는 햄버거 드로어로, 편집기 분할 화면은 탭 전환(에디터/미리보기)으로 대체합니다.
- 화면별 상세 구성·동작은 다음 단계인 화면설계서에서 다룹니다.

## 업로드·파일 관리 UX 확장 (2026-08-15)

기존 API를 그대로 쓰는 클라이언트 UX 확장. 서버 변경 없음.

**업로드 입구 (v0.4)**
- 클립보드 붙여넣기: 입력창 밖에서 Ctrl+V — 이미지는 즉시 업로드(자동 이름), 텍스트는 파일명 입력 후 md로 저장. 편집기·이름변경·대화상자 등 입력 요소에 포커스가 있으면 가로채지 않는다.
- 트리 폴더별 드롭: OS 파일을 트리의 폴더 위에 떨어뜨리면 해당 폴더로 업로드 (기존 하이라이트 재사용).
- 전역 드롭 (v0.5): 개별 드롭 존 밖이라도 앱 화면 어디에 놓든 최상위로 업로드된다 (window 레벨에서 브라우저 기본 동작을 막고 수거).

**다중 선택 (v0.4)**
- 진입: Ctrl+클릭(PC) 또는 컨텍스트 메뉴 "선택"(터치). 선택 모드에서는 행 클릭이 열람 대신 토글, Shift+클릭은 보이는 순서 기준 범위 선택.
- 일괄 작업 바(패널 상단): 이동(폴더 선택 모달) · 삭제(확인 후) · 해제. 폴더는 다중 선택 대상에서 제외(파일만).
- 이동(단일 DnD 포함)은 실행 취소 토스트 5초 제공. 삭제는 휴지통 도입(로드맵) 전까지 확인 대화상자 유지.

**폴더 업로드·충돌 처리 (v0.5)**
- 폴더 선택 업로드(webkitdirectory, PC 전용)와 폴더 드래그(항목 재귀 순회) 지원. 폴더 체인은 기존 폴더 API로 클라이언트가 생성 후 파일 업로드.
- 이름 충돌은 업로드 전 클라이언트가 검사해 일괄 선택 대화상자 제공: 덮어쓰기(텍스트=버전 스냅샷 후 본문 교체, 바이너리=삭제 후 재업로드) / 이름 바꿔 저장(자동 " (2)" 접미) / 건너뛰기.

**휴지통·격자 보기·공유 시트 (v0.6)**
- 휴지통: 파일 삭제는 soft delete — 30일 보관 후 자동 영구 삭제 (상세는 ERD·API 명세). 삭제 확인 대화상자를 없애고 실행 취소(복원)로 대체. 폴더 삭제 시 구조는 삭제되고 파일은 휴지통으로.
- 격자 보기: 내 파일 패널의 목록/격자 토글(기기별 취향이라 localStorage 저장). 격자는 이미지 썸네일(/raw) 중심의 열람용이고, 다중 선택 등 정리 작업은 목록 보기가 담당.
- 공유 시트: manifest share_target(POST /share-target, /api/v1 밖이라 인증 직접 검사) — 폰 공유로 파일·텍스트 수신, 이름 충돌은 자동 개명, 실패는 조용히 건너뛰고 홈으로.

## 탭 바 + 분할 보기 (2026-08-27, v0.15)

서버 변경 없는 클라이언트 확장. **"열려 있다"(탭)와 "보이고 있다"(분할)를 분리**하는 것이 핵심 설계.

**탭 바 (SCR-153, 항상 표시)**
- 본문 영역 맨 위 한 줄. 문서를 열면 탭이 쌓이고, 이미 열린 문서는 그 탭으로 전환. 탭 클릭 = 전환, 호버 시 × = 닫기, 넘치면 탭 바 안에서 가로 스크롤.
- 몰입 모드에서는 탭 바도 숨긴다 (몰입 모드의 약속: 본문만).
- 탭·분할 상태는 세션 한정(새로고침 시 딥링크의 활성 문서 하나만 복원). URL 라우팅은 기존 그대로 활성 문서만 `/f/{id}`.

**분할 (SCR-154)**
- 배치 규칙: **보던 문서는 제자리, 새 문서가 새 칸으로.** 진입은 파일 컨텍스트 메뉴(⋯/우클릭)의 "분할로 열기"와 PC의 Alt+클릭 (Ctrl+클릭은 다중 선택이 선점).
- 데스크톱(768px 이상): 프리셋 — 2개=좌우, 3개=좌1+우2, 4개=2×2 (상한 4). 주 구분선 드래그로 비율 조절(20~80%).
- 모바일(768px 미만): **상하 2분할까지만**. 3번째부터는 탭 대기.
- 활성 칸: 마지막에 조작한 칸에 강조 테두리. 탭 클릭·단축키는 활성 칸에 적용. 이미 화면에 있는 문서의 탭을 누르면 그 칸을 활성화.
- 자리 바꾸기: 2분할일 때 구분선 가운데의 ⇄ 버튼 (경우의 수가 하나라 버튼이 드래그보다 빠름). 탭 드래그 배치는 후속(v2).
- 칸 닫기: 각 칸의 × 는 칸만 닫고 탭은 남는다. 탭 × 는 문서를 완전히 닫는다.
- 각 칸은 독립 뷰어 — 글자 배율·스크롤·목차·편집이 문서별로 따로. 분할 중 E(편집)는 활성 칸 자리만 편집기로 바뀐다 (왼쪽 보면서 오른쪽에 쓰기).

**문서 내부 링크 (같은 릴리스)**
- md 문서 속 상대 경로 링크(`[이름](부록/용어집.md)`)는 브라우저 이동 대신 **그 파일을 탭으로** 연다. Alt+클릭 = 분할로. 링크를 품은 문서의 폴더에서 출발해 `../`·하위 폴더명을 클라이언트가 트리에서 풀며, 서버 변경 없음.
- 줄 번호 앵커(`#L16-L26`)가 붙으면 파일을 열고 **그 줄로 스크롤 + 형광펜 하이라이트** (코드 뷰어).
- 대상이 트리에 없으면(업로드 범위 밖·공유 문서 기준) "연결된 파일을 찾을 수 없습니다" 토스트. 외부 URL(`http…`)과 `#제목` 앵커는 기존 브라우저 동작 그대로.
