# docvault로 배우는 개발 입문

코딩을 한 번도 해본 적 없는 사람이, 자기가 실제로 운영하는 서비스(docvault)를 교재 삼아 개발의 기초부터 운영까지 배우는 자료입니다. **아무것도 모른다고 가정하고** 진행합니다.

일반 교재와 다른 점: 모든 개념을 남의 예제가 아니라 **우리 코드**로 설명합니다. 배운 개념이 실제로 어느 파일 몇째 줄에 있는지 바로 확인할 수 있습니다.

### 2부. [프로그래밍 언어 마스터 — JavaScript / TypeScript / React](2부-프로그래밍-언어-마스터.md) ✅

한 파일에 개관 + 8개 장. 순서대로 읽으세요 — 각 장이 앞 장의 개념을 딛고 올라갑니다.

개관(코드를 소리 내어 읽는 법) → 2-1 값·변수·연산자 → 2-2 함수(콜백·클로저) → 2-3 객체와 배열(참조·스프레드·구조 분해·map) → 2-4 흐름과 에러 → 2-5 비동기(Promise·async/await) → 2-6 모듈(import/export) → 2-7 TypeScript(유니온·제네릭·좁히기·zod) → 2-8 React

### 3부. [프로젝트 단위 — 도구, 데이터, 그리고 요청 하나의 일생](3부-프로젝트-단위.md) ✅

3-1 npm(부품 창고와 계약서) → 3-2 Git(시간을 다루는 도구) → 3-3 서버 해부(Hono·미들웨어·deny by default) → 3-4 데이터베이스(SQL·Drizzle·마이그레이션·트랜잭션) → 3-5 보안(해시·JWT·httpOnly·인가) → **3-6 총결산: Ctrl+S 한 번의 왕복 12단계**

### 4부. [운영 — 내 코드가 세상에서 계속 돌게 하기](4부-운영.md) ✅

4-1 Docker(이미지·컨테이너·Dockerfile 해부) → 4-2 compose 해부(볼륨·헬스체크·프로필) → 4-3 비밀 관리(.env) → 4-4 CI 해부(push가 배포가 되기까지) → 4-5 운영 감각(백업·업데이트·장애). 손 실습 편은 [GCP 배포 가이드](../GCP-배포-가이드.md)와 한 쌍입니다.

## 읽는 법

- 순서대로 읽어도 되고, 궁금한 장부터 펼쳐도 됩니다. 각 장 첫머리의 체크리스트가 "이 장을 끝내면 알게 되는 것"입니다.
- 각 장의 **직접 해보기**는 건너뛰지 마세요. 읽어서 아는 것과 손으로 겪어서 아는 것은 다릅니다.
- docvault에 업로드해서 읽으면 읽던 위치·즐겨찾기가 동기화됩니다 (우리가 만든 기능을 우리 교재에 쓰는 것).
