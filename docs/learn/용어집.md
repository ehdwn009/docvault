# 용어집

대화·작업 중 등장한 용어의 한 줄 사전. 새 용어가 등장할 때마다 한 줄씩 추가됩니다. 한글 용어는 가나다순, 영문 용어는 뒤쪽에 알파벳순.

- **값** — 프로그램이 다루는 재료. 숫자, 문자열, 불리언, null/undefined가 기본 종류다.
- **개발 서버** — 코드를 고치면 즉시 반영해서 보여주는 연습용 서버. 내 컴퓨터에서만 돌고, 진짜 서비스와 무관하다.
- **개발자 도구** — 브라우저에 내장된 관찰 도구(F12). 네트워크 탭에서 요청/응답이 오가는 걸 실시간으로 볼 수 있다.
- **객체** — 칸마다 이름표가 붙은 서랍장 `{ role: 'admin' }`. 꺼낼 땐 점을 찍는다(`user.role`). JSON과 같은 모양.
- **경로(path)** — 파일의 전체 주소. 왼쪽이 큰 폴더, 오른쪽으로 갈수록 그 안. 드라이브부터 다 적으면 절대 경로, 현재 위치 기준이면 상대 경로(`..`은 한 칸 위).
- **구조 분해** — 그릇에서 값을 꺼내며 바로 이름 붙이는 축약 문법. `const [panel, setPanel] = useState(...)`(배열은 순서대로), `const { name } = user`(객체는 이름으로).
- **낙관적 잠금** — "편집 시작 시점의 updatedAt"을 저장 요청에 동봉해, 그 사이 남이 먼저 저장했으면 409로 거부하는 기법. 소리 없는 덮어쓰기를 막는다.
- **널 병합(`??`)** — 왼쪽이 null/undefined일 때**만** 오른쪽 기본값을 쓴다. 0이나 빈 문자열도 정상 값인 곳에선 `||` 대신 이것.
- **단락 평가** — `&&`/`||`가 왼쪽만 보고 결론이 나면 오른쪽을 실행하지 않는 것. `조건 && 실행()`은 한 줄짜리 if다.
- **도메인** — 서버 컴퓨터의 이름. 진짜 주소는 숫자 IP인데, 사람이 외우기 좋게 이름을 붙이고 DNS가 번역해 준다.
- **라우트** — "이 주소+메서드의 요청은 이 함수가 처리한다"는 등록. 우리 서버는 도메인별 파일(routes/files.ts 등)로 나눈다.
- **렌더러(renderer)** — 원본(예: 마크다운 글자)을 받아 사람이 보는 최종 모습(꾸며진 화면)으로 그려주는 부품.
- **리터럴 유니온** — 특정 값들만 허용하는 타입 `'user' | 'admin'`. 가능한 값이 유한하면 전부 나열해서 오타를 빌드 전에 잡는다.
- **마이그레이션** — DB 구조 변경의 이력 관리. 스키마를 고치고 `db:generate`로 차이를 SQL로 뽑으면, 서버가 기동 시 순서대로 자동 적용한다.
- **매개변수 / 인자** — 매개변수는 함수를 정의할 때 지은 빈칸의 이름, 인자는 호출할 때 실제로 넣는 값.
- **매니페스트(manifest)** — 묶음에 함께 넣는 목록표. 내보내기 ZIP의 `docvault-manifest.json`은 파일 경로·태그·즐겨찾기처럼 파일 자체에는 남지 않는 정보를 보존한다.
- **메서드** — HTTP 요청의 동사. GET(읽기), POST(만들기), PUT(바꾸기), DELETE(지우기).
- **모듈** — 역할 하나를 맡은 코드 파일. export로 공개하고 import로 빌려 쓴다. 경로가 `./`로 시작하면 우리 파일, 이름만이면 npm 부품.
- **문자열** — 글자 값. 따옴표로 감싼 것이 "이건 글자다"라는 표시다(`'admin'`).
- **문지기(guard)** — 함수 첫머리에서 자격 없는 경우를 즉시 return으로 돌려보내는 패턴. "실패를 위에서 걷어내고 본론은 평평하게". 서버 라우트 대부분이 이 구조다.
- **미들웨어** — 모든 요청이 본론에 닿기 전에 거쳐 가는 공용 검문소. 우리 서버의 인증(로그인 검사)이 미들웨어다.
- **바이너리** — 글자가 아닌 파일(이미지, PDF...). 메모장으로 열면 깨져 보인다. ↔ 텍스트 파일.
- **배열** — 이름표 없이 순서대로 줄 세운 목록 `['md', 'html']`. map(변환)·filter(골라내기)·find(하나 찾기)·sort(정렬)·includes(포함 여부) 같은 명령을 시킬 수 있다.
- **변수** — 값에 이름을 붙여 두는 것.
- **볼륨** — 컨테이너 안의 폴더를 진짜 디스크에 연결하는 것(`./data:/app/data`). 컨테이너는 소모품이라, 남아야 할 데이터는 볼륨에 둔다. `const`는 "다시 안 바꿈"(기본), `let`은 "바뀔 수 있음". `=`는 "같다"가 아니라 "담아라"다.
- **불리언** — 참(true)/거짓(false) 딱 두 값. 조건 검사의 재료.
- **브랜치** — Git 역사의 갈래(실험용 평행우주). 우리는 아직 main 한 줄기만 쓴다.
- **비동기** — 시간이 걸리는 일을 기다리지 않고 예약해 두고 넘어가는 방식. 화면이 얼지 않는 비결.
- **빌드** — ① 타입 검사 ② TypeScript를 브라우저가 읽을 수 있는 순수 JavaScript로 변환. `npm run build`가 하는 일. **타입은 이때 사라진다** — 그래서 경계엔 zod.
- **삼항 연산자** — `조건 ? A : B`. "맞으면 왼쪽(A), 아니면 오른쪽(B)". 짧은 갈림길용 문법.
- **샌드박스(sandbox)** — 프로그램을 격리된 모래상자에서 실행해 밖(세션 쿠키·부모 창·API)에 손대지 못하게 하는 것. 우리 HTML 뷰어의 iframe이 이 모드로 돈다.
- **상태 코드** — 응답에 붙는 세 자리 결과 번호. 200 성공, 401 로그인 필요, 403 권한 없음, 404 없음, 500 서버 잘못. 40x는 요청 쪽, 50x는 서버 쪽 문제.
- **서버** — 요청을 받아 검사하고 응답하는 쪽(식당의 주방). 지켜야 할 것(비밀번호·권한·데이터)은 전부 여기 둔다.
- **소프트 삭제(soft delete)** — 행을 지우는 대신 `deleted_at` 같은 표시만 찍는 삭제. 복원이 가능해지는 대신, 그 테이블을 읽는 모든 쿼리에 "표시 없는 것만" 필터가 필요해진다.
- **스코프** — 변수가 보이는 범위. 안에서 밖은 보이고, 밖에서 안은 안 보인다.
- **스테이지** — Git에서 "다음 커밋에 담을 것"을 골라두는 중간 구역. `git add`가 여기로 올리는 일.
- **스트리밍** — 전체를 다 만들어 놓고 주는 대신, 만들어지는 족족 흘려보내는 방식. 메모리를 아끼는 대신 전체 크기를 미리 알 수 없다(내보내기 ZIP이 이 방식).
- **스프레드(`...`)** — 그릇의 내용물을 펼치는 세 글자. 새 그릇 복사(`[...a]`, `{ ...b }`)에 쓰고, 받는 자리에서는 "나머지 모으기"가 된다.
- **시맨틱 버저닝** — `주.부.수` 버전 약속: 주=호환 깨짐, 부=기능 추가, 수=버그 수정. `^4.7.0`은 "4.x 안에서 최신 허용".
- **실행** — 컴퓨터가 코드(명령서)를 위에서부터 한 줄씩 따라 하는 일.
- **옵셔널 체이닝(`?.`)** — "있으면 꺼내고 없으면 undefined". `selected?.id` — null 서랍장에 점 찍고 즉사하는 것을 막는다.
- **외래 키** — "이 칸에는 저 테이블의 id에 실존하는 값만"이라는 DB 제약(`files.owner_id → users.id`). cascade를 걸면 원본 삭제 시 연쇄 삭제된다.
- **요청/응답** — 웹의 유일한 대화 형식. 클라이언트가 요청 하나를 보내면 서버가 응답 하나를 돌려준다. 이 규칙의 이름이 HTTP.
- **워크스페이스** — 한 저장소 안의 작은 프로젝트들(우리는 client와 server). 명령어의 `-w client`가 "client 쪽에서"라는 뜻.
- **이미지(Docker)** — 앱 + 실행 환경 전부를 떠 놓은 복사본 틀. 이 틀로 찍어낸 실행체가 컨테이너 — 어느 컴퓨터에서든 똑같이 돈다.
- **인증 / 인가** — 인증은 "너 누구야?"(실패=401, authGuard 담당), 인가는 "그걸 할 자격 있어?"(실패=403, canReadFile류 담당).
- **제네릭** — 타입의 빈칸. `api<Tree>('/tree')` — 정의는 `<T>`로 뚫어두고 호출자가 꺾쇠로 채운다.
- **조건문** — 갈림길. `if (조건) 행동` — 조건이 참일 때만 행동한다. `!`는 "아니다".
- **좁히기(narrowing)** — 검사를 통과한 코드 구간에서 타입이 자동으로 구체화되는 것. `if (id === null) return` 뒤에서 id는 그냥 number.
- **참조** — 객체/배열 변수에는 값이 아니라 "그릇의 위치"가 담긴다. `const b = a`는 같은 그릇 공유 — 진짜 복사는 스프레드로.
- **컨테이너** — 이미지(틀)로 찍어낸 실행체. 격리된 방에서 돌고, 업데이트 때마다 부수고 새로 찍는 소모품이다.
- **커밋** — 그 순간 프로젝트 전체의 스냅샷 + 누가 언제 왜(메시지). 게임의 세이브 포인트. 우리 규칙: 기능 하나 = 커밋 하나, "타입: 요약".
- **컴포넌트** — 화면 조각을 돌려주는 함수. 이름이 대문자로 시작한다(`FileTree`, `Viewer`).
- **코드** — 프로그램(명령서)을 사람이 읽고 쓸 수 있게 글자로 적은 것.
- **콜백** — "나중에 실행해 달라"고 값으로 넘기는 함수. 넘길 때 괄호를 붙이면 그 자리에서 즉시 실행돼 버린다 — 최다 발생 버그.
- **클라이언트** — 요청하는 쪽(식당의 손님). 우리 프로젝트에선 브라우저에서 도는 `client/` 코드. 사용자가 조작할 수 있는 영역이라 믿지 않는 게 원칙.
- **클로저** — 함수가 자기가 태어난 곳의 변수를 배낭처럼 기억하는 것. 호출마다 배낭이 따로다.
- **타입** — 값에 붙이는 라벨(`: string` = "글자만"). 덕분에 실수를 실행 전에(저장하는 순간) 잡을 수 있다. TypeScript = JavaScript + 타입.
- **터미널** — 마우스 대신 글자 명령으로 컴퓨터를 조작하는 창. 개발 도구 대부분은 화면이 없어서 여기서 다룬다.
- **테이블** — DB의 표. 가로줄이 행(데이터 한 건), 세로줄이 열(속성).
- **텍스트 파일** — 순수한 글자로만 된 파일(.md, .ts, .json...). 코드 파일도 전부 텍스트 파일이다.
- **템플릿 리터럴** — 백틱(`` ` ``) 문자열. `${ }` 구멍에 값을 끼워 넣을 수 있다 — `` `/api/v1${path}` ``.
- **트랜잭션** — "이 묶음은 전부 성공하거나 전부 없던 일"을 DB가 보장하는 장치. 함께 성공해야 말이 되는 변경들(스냅샷+저장+정리)을 묶는다.
- **패치노트** — 사용자에게 보여주는 변경 내역. 우리 앱은 루트 `CHANGELOG.md`가 원본이다.
- **포트** — 한 컴퓨터에 나 있는 여러 개의 문 번호. 웹 기본 문은 443(https). 개발 중엔 5173(화면)·3000(서버) 두 문을 쓴다.
- **프로그램** — 컴퓨터에게 시킬 일을 순서대로 적은 명령서 뭉치.
- **플러그인** — 기존 프로그램에 끼워 넣어 기능을 더하는 부품. 프로그램 본체를 안 고치고 동작을 바꿀 수 있다.
- **함수** — 입력을 넣으면 결과가 나오는 이름 붙인 기계. 이름·입력·출력만 읽으면 속을 몰라도 쓸 수 있다. 함수도 값이다 — 변수에 담고 인자로 넘긴다.
- **환경변수** — 코드 밖(실행 환경)에서 주입하는 설정 값. 비밀(JWT_SECRET)은 코드가 아니라 여기(.env)에만 둔다 — 견본은 .env.example로 커밋.
- **헬스체크** — 주기적으로 `/health`를 찔러 앱 생존을 확인하는 장치. 죽으면 재시작 정책과 맞물려 되살린다.
- **해시** — 되돌릴 수 없는 반죽. 비밀번호는 해시만 저장하고(서버도 원문을 모름) 반죽끼리 비교해 검사한다. Git의 커밋 지문도 같은 원리.
- **호출** — 함수를 실제로 돌리는 것. `이름(...)` — 괄호가 실행 버튼이다. 괄호 없이 이름만 쓰면 "기계 자체"를 가리킬 뿐 실행되지 않는다.
- **화살표 함수** — 이름 없는 즉석 함수를 만드는 짧은 문법. `(c) => c.json(...)` — "c를 넣으면 → c.json(...)이 나온다". 중괄호를 열면 return을 직접 써야 한다.
- **확장자** — 파일 이름 끝의 `.md` 같은 꼬리표. "이 파일을 어떻게 취급할지"의 힌트.
- **any** — "이 값은 타입 검사를 하지 마"라는 타입. 안전망에 구멍을 내는 것이라 우리 프로젝트에선 금지. 대안은 unknown + 좁히기.
- **API** — 사람이 보는 화면이 아니라, 프로그램이 프로그램에게 데이터를 요청하는 창구. 우리 서버는 전부 `/api/v1/` 아래에 모여 있다.
- **async/await** — 예약(Promise)을 순차 문장처럼 쓰는 문법. `await`는 "**이 함수 안에서만** 결과를 기다림" — 바깥 화면은 계속 돈다.
- **base URL** — 상대 주소(`#s31`, `./img.png`)를 절대 주소로 완성할 때 기준이 되는 주소. srcdoc iframe은 자기 주소가 없어 부모의 것을 물려받는다 — HTML 뷰어 흰 화면 사건의 범인 (→ 인박스).
- **bcrypt** — 비밀번호 해시 전용 부품. 일부러 느리게(반죽 횟수 조절) 만들어 무차별 대입을 비경제적으로 만든다.
- **CI/CD** — push를 방아쇠로 빌드·검사·배포를 기계가 매번 같은 방식으로 하게 만든 것. 우리는 GitHub Actions → GHCR → 서버 pull.
- **CommonMark** — 마크다운의 표준 규격. "어떤 글자를 볼드로 볼 것인가" 같은 해석 규칙을 정해 둔 약속. 한글 조사와 만나면 허점이 있다 (→ 인박스의 볼드 사례).
- **Docker** — 앱과 실행 환경을 통째로 포장(이미지)해 어디서든 똑같이 돌리는 도구. Dockerfile이 굽는 레시피, compose가 띄우는 계약서.
- **Drizzle** — TypeScript로 DB 스키마와 쿼리를 쓰게 해주는 부품. 스키마에서 타입이 저절로 나오고, snake_case↔camelCase 변환을 담당한다.
- **fetch** — 브라우저 내장 HTTP 요청 기계. 주의: 404여도 던지지 않으므로 `res.ok` 검사가 필요하다 (우리 api()가 대신 해줌).
- **GHCR** — GitHub의 컨테이너 이미지 창고. CI가 구운 이미지를 여기 올리고, 서버는 여기서 pull한다.
- **GitHub Actions** — "push 같은 사건이 나면 이 절차를 실행하라"는 자동화. `.github/workflows/`의 yml 파일이 절차서다.
- **Hono** — 우리 서버의 뼈대(프레임워크). 주소·메서드별 처리 함수를 등록해 두면 맞는 요청에 실행해 준다.
- **HTTP** — 웹의 대화 규칙(요청/응답의 형식). 앞에 s가 붙으면(https) 암호화된 버전.
- **httpOnly** — "이 쿠키는 JavaScript로 읽을 수 없음" 설정. XSS가 성공해도 세션 통행증만은 못 훔치게 하는 방어막.
- **IP** — 컴퓨터의 진짜 주소(숫자). `34.x.x.x` 같은 형태. 도메인은 이것의 별명이다.
- **JSON** — `{"이름": 값}` 꼴의 데이터 글자 양식. 사람도 프로그램도 읽기 쉬워서 API의 표준 양식이 됐다.
- **JSX** — HTML처럼 생긴 JavaScript. `{}`는 JS 구멍, class 대신 className, 대문자 태그는 컴포넌트. `.tsx`의 x가 이것.
- **JWT** — 서명된 통행증. 내용(사용자 번호·만료)은 공개지만, 서버 비밀키(JWT_SECRET) 도장 덕에 위조가 불가능하다. 암호화가 아니라 서명.
- **key** — 목록 렌더링(map)에서 각 항목에 붙이는 이름표. React가 다시 그릴 때 "같은 항목"을 알아보는 근거.
- **localhost** — "내 컴퓨터 자신"을 가리키는 특수 주소. `localhost:5173`은 "내 컴퓨터의 5173번 문".
- **NaN** — "숫자 아님(Not a Number)" 특수 값. 숫자가 아닌 것을 숫자 계산하면 에러 대신 이게 나온다.
- **npm** — 부품 창고(레지스트리)에서 부품을 받아 관리하는 도구. package.json이 희망 목록, package-lock.json이 정확한 설치 영수증.
- **path traversal** — 사용자 입력의 `../`로 저장 폴더를 탈출해 남의 파일에 닿는 공격. 입력이 경로가 되는 곳은 반드시 정규화·검증한다.
- **postMessage** — 격리된 창(iframe)과 부모가 대화하는 유일한 공식 통로. 쪽지(객체)를 던지고, 받는 쪽은 보낸 이(`e.source`)를 확인한 뒤에만 믿는다.
- **Promise** — 예약증. 대기 중 → 이행됨(값) 또는 거부됨(에러) 세 상태. `Promise.all([...])`은 여러 예약을 동시에 걸고 전부 오면 진행.
- **props** — 부모 컴포넌트가 자식에게 주는 재료. 위에서 아래로만 흐르고, 자식은 읽기만 할 수 있다.
- **React** — "상태가 바뀌면 화면을 다시 그린다"는 사상의 화면 라이브러리. 화면 = 함수(상태).
- **SPA** — 단일 페이지 앱. 서버는 모르는 주소를 전부 index.html로 넘기고, 화면 전환은 브라우저 안의 React가 담당한다 (딥링크가 동작하는 원리).
- **SQL** — DB에게 말 거는 언어. SELECT(읽기)·INSERT(추가)·UPDATE(수정)·DELETE(삭제) + WHERE/ORDER BY/LIMIT.
- **SQLite** — 서버 없이 파일 하나로 동작하는 DB. 우리 `data/` 폴더의 그 파일 — 그래서 폴더가 곧 백업 단위다.
- **state** — 컴포넌트가 스스로 기억하는 값. set 함수로 바꾸면 React가 다시 그린다. 직접 대입은 무효.
- **truthy / falsy** — if가 모든 값을 참/거짓으로 치는 규칙. falsy는 딱 6개: `false, 0, '', null, undefined, NaN`. 나머지 전부 truthy.
- **undefined** — "아직 아무것도 안 담김". 오타로 없는 칸을 읽어도 에러 대신 이게 조용히 나온다 — TypeScript가 필요한 이유. (null은 "일부러 비워둠")
- **unknown** — "뭔지 모름 — 좁히기 전엔 못 씀". 모르는 값을 안전하게 받는 any의 대안.
- **URL** — 웹 주소 전체. 프로토콜(대화 방식) + 도메인(어느 컴퓨터) + 포트(몇 번 문) + 경로(무엇을)로 읽는다.
- **useEffect** — "그린 다음 할 일"을 등록하는 훅. 돌려주는 함수는 청소용(해제·정리). 끝의 배열은 "언제 다시 실행할지".
- **useMemo** — 재료가 안 바뀌었으면 비싼 계산을 재사용하는 훅.
- **useState** — 상태를 선언하는 훅. `[현재값, 바꾸는함수]`를 돌려준다.
- **XSS** — 악성 스크립트를 페이지에 심는 공격. 성공해도 피해를 줄이도록 세션 쿠키는 httpOnly로 둔다.
- **zod** — 실행 중에 데이터 모양을 검사하는 부품. 빌드 때 사라지는 타입이 못 지키는 경계(외부 입력)를 지킨다.
