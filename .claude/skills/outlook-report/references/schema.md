# 완성본 형식 (out/report.json, format 1)

화면 틀(`server/assets/outlook-template.html`)과 대조(`server/src/lib/outlook/verify.ts`)가 읽는 한 파일. 모양의 정의는 `server/src/lib/outlook/schema.ts`. 리더가 쓰고 `npm run outlook:job -w server -- build $W`가 원문과 대조한다.

**화면에는 글·표·도표와 각주 번호만 나온다. 근거(`facts`)는 화면에 보이지 않지만 반드시 붙인다** — 대조가 그것으로 숫자를 맞춘다.

```jsonc
{
  "format": 1,
  "meta": {
    "edition": "small",                         // small(작은 판) | big(큰 판)
    "title": "글로벌 리서치 동향",
    "subtitle": "…",                            // 한 줄
    "label": "2026년 12월 둘째 판",
    "since": "2026-11-21", "until": "2026-12-13",   // since = 직전 판의 until 다음 날(이 예는 [지금 만들기] 판이 없었을 때)
    "baseline": "2027 세계 경제 전망(2026-11-20 시범)",   // 작은 판만
    "test": false,                              // 시험 운행이면 true — 화면 머리에 "시험 운행"
    "generator": "outlook-report v2"
  },
  "summary": [ { "text": "… 문장[1][2]. …", "facts": ["gdpImf"] } ],      // 1~5문단
  "sections": [
    { "id": "changed", "title": "달라진 것",                                      // id는 영문 소문자·숫자·-
      "blocks": [
        { "type": "p", "text": "…[3]", "facts": ["…"] },
        { "type": "bullets", "items": [ { "lead": "짧은 머리(선택)", "text": "…[4]", "facts": ["…"] } ] },
        { "type": "table", "title": "표 제목(선택)", "note": "표 아래 설명(선택)",
          "columns": ["지표", "이전", "이번", "주"], "rows": [["세계 성장률", "3.1%", "3.3%", "[5]"]], "facts": ["…"] },
        { "type": "chart", "title": "도표 제목", "note": "기준 설명(선택)", "unit": "%",
          "rows": [ { "label": "이름", "sub": "작은 설명(선택)", "value": 3.3, "text": "3.3%" } ], "facts": ["…"] }
      ] }
  ],
  "about": { "title": "맺음", "text": "…", "facts": [] },                         // 큰 판은 "이 보고서에 대하여"
  "notes": [ { "n": 1, "org": "IMF", "title": "World Economic Outlook Update", "date": "2026-11-26", "url": "https://…" },
             { "n": 2, "org": "IMF", "title": "World Economic Outlook", "date": "2026-10-14", "url": "https://…", "context": "이전 값 — 기준선 판의 근거" } ],
  "facts": {
    "gdpImf": { "note": 1, "quote": "원문 글 그대로(500자 안)" },
    "gdpPrev": { "note": 2, "quote": "원문 글 그대로" },
    "chg":    { "calc": "3.3 - 3.1 = 0.2", "uses": ["gdpImf", "gdpPrev"] }
  }
}
```

## 각주와 주 목록

- 본문 글에 `[n]`으로 단다. 붙여 쓰면(`[3][4]`) 화면에서 위첨자 하나로 묶인다. **굵게**는 `**…**`(아껴 쓴다).
- 주 번호는 1부터 끊김 없이, **본문에 처음 나오는 순서대로**(제목 · 부제 · 요약 · 절 · 맺음 순으로 읽는다). 본문이 가리키지 않는 주, 주 목록에 없는 번호가 있으면 build가 멈춘다.
- `date`는 원문의 발표일. 읽는 기간 밖이면 build가 멈춘다 — 비교 맥락으로만 쓰는 기간 밖 자료(기준선의 이전 값 등)는 `context`에 이유를 적는다(`"context": "이전 값 — 기준선 판의 근거"`).
- 뉴스로만 확인한 출처는 그 기사의 매체 · 제목 · 주소를 적는다.

## 근거(facts)와 대조 규칙

- **인용** `{ "note": n, "quote": "…" }` — 주 n의 원문 글(grab이 받은 파일)에 글자 그대로 있어야 한다(띄어쓰기·줄바꿈만 무시). 원문을 받지 못한 출처의 인용은 "원문 확인 못 함"으로 세고 통과시킨다 — 그 비율을 보고한다.
- **계산식** `{ "calc": "(왼쪽 식) = 값", "uses": ["근거 id", …] }` — 왼쪽을 다시 계산해 값과 견준다(끝자리 1까지 차이는 받는다). 숫자와 `+ − × ÷ ^ ( )`만. 식에 쓴 숫자는 `uses`의 근거 안에 있어야 한다(1 · 10 · 12 · 100 · 1000은 예외). 감소는 값에 `−`.
- **문장 속 숫자**: 글(요약 · 문단 · 글머리표 · 표의 칸 · 도표의 이름·값 · 맺음 본문)에 나온 숫자는 그 글의 `facts`가 가리킨 근거 안에 있어야 한다. 제목 · 부제 · 절 제목에는 `facts` 칸이 없으므로 대조 대상 숫자를 쓰지 않는다(쓰면 멈춘다). 맺음의 제목은 대조하지 않는다. 인용 속 숫자 가운데 근거로 쓰이는 것은 값이다 — 뒤에 년·월·일·위·분기가 붙은 수는 빠진다(영어 인용의 "in 2026", "November 20" 같은 수는 남지만 근거 쪽 수가 늘 뿐이라 해가 없다). 반올림(3.42 → 3.4)은 같은 것으로 본다. 방향 기호 ▲는 근거가 0 이상이어야 하고, ▼는 근거가 계산식일 때만 0 이하인지 본다(인용은 원문이 감소를 글로만 적었을 수 있어서).
- **대조하는 숫자**: 소수점이나 쉼표가 있는 수, 100 이상인 수, 단위(% · 배 · 억 · 조 · 달러 · 원 · 톤 · 만 · bp · 엔 · 유로 · 위안 · 파운드 · 배럴)가 붙은 수. %p는 %로 친다.
- **대조하지 않는 숫자**: 각주 번호, 연도로 보이는 수(쉼표 없는 1900~2100 정수 — 금액은 반드시 쉼표를 찍는다: "2,000억"), 날짜와 순서(3분기, 11월, 두 번째), 지수·묶음 이름 속 숫자(S&P 500, 닛케이 225, G7, ASEAN+3), 단위 없는 작은 개수, "100분의 1%포인트"처럼 '분의' 앞뒤의 수. 이것은 리더가 원문과 맞는지 본다.
- **도표**의 `value`는 그 줄의 `text`에 적힌 값과 같아야 한다(그림과 글이 어긋나지 않게).
- **틀리면**: 제목 · 부제 · 요약 · 절 제목 · 맺음이 틀리면 build가 멈춘다("고쳐야 받습니다"). 본문 블록이 틀리면 그 블록(글머리표는 그 항목)이 빠진다. 다 빠진 절은 절째 빠지고, 남은 절이 2개 미만이거나 빠진 블록(글머리표는 항목)이 본문 블록 수의 30%를 넘으면 멈춘다.
- 물결표(~)와 달러 기호($)가 화면 글에 있으면 멈춘다.
