# 수집 노트 양식 (F가 쓰고 V가 검증본으로 고친다)

```
# <묶음 이름> 수집 노트 — <판 이름>

## 1. 검색 기록
| 순번 | 검색어(그대로) | 언어 | 결과 수 | 걸린 주요 결과 | 쓸모 있었나 · 이 검색으로 정한 것 |
- 검색 할당 중 몇 회를 썼고 몇 회 남았는지(할당은 지시문에 있다). 다 썼으면 "검색 할당 소진"이라고 적는다.

## 2. 기관별 결과
### <기관 이름>
- 상태: 찾음 / 기간 안 새 글 없음 / 아직 안 나옴(예정) / 접근 막힘 / 유료·고객 전용
- 어떻게 찾았나: 발간 페이지 / 달력 / 열린 검색
- 기간 안 글 목록: | 제목 | 발표일 | 주소 | 받음(grab 결과: 받음·못 받음(이유)) | 골랐나 |
- 고른 글과 이유:
- 기관이 앞세운 메시지(그 기관의 순서대로, 3~5개): 메시지마다 원문 인용(받은 원문 파일에서 글자 그대로)과 근거 등급
- 숫자: | 지표 | 값 | 시점 | 기준 | 원문 인용(글자 그대로) | 근거 등급 | 주소 |
- 어느 조직인가: 연구 부서 / 자산관리 고객용 / 보도자료 / 언론 보도
- 이해관계: 이 기관이 파는 것·지키려는 것과 주장이 겹치는 곳(해석이면 "해석:")

## 3. 추가 후보
목록 밖 기관이 이 기간에 비중 있는 글을 냈으면 이름 · 제목 · 주소만.

## 4. 접근 기록
| 사이트 | 결과(받음 / HTTP 코드 / 글이 거의 없음 / 유료) | 대신 쓴 경로 |
```
